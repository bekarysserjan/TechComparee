# TechCompare Frontend

## Запуск

1. Установите Node.js 20 или новее.
2. Откройте терминал в папке `frontend`.
3. Выполните `npm install`.
4. Запустите интерфейс командой `npm run dev`.
5. Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Backend должен быть запущен отдельно на `http://localhost:8080`, а база данных должна быть подключена и содержать данные.

## Как устроено

- `src/main.jsx` — логика приложения, запросы к API, выбор устройств, сравнение и диаграммы. Комментарии в коде на русском.
- `src/style.css` — стили, бело-оранжевая палитра, тёмная тема и адаптация для телефона.
- `vite.config.js` — перенаправляет `/api` запросы на Spring Boot `localhost:8080`.

Интерфейс получает смартфоны и ноутбуки из `GET /api/v1/smartphones` и `GET /api/v1/laptops`. Поиск работает по мере ввода каждой буквы и показывает список подходящих устройств; полный каталог не выводится до начала поиска. Сравнение использует `POST /api/v1/comparisons/smartphones` или `POST /api/v1/comparisons/laptops`. После успешного сравнения автоматически запрашивается итог от AI через `POST /api/v1/ai/overview`. Кнопка повторного объяснения остаётся доступной. Изображения загружаются из поля `imageUrl`, которое возвращает backend. Данные устройств не дублируются во frontend.

## Важно

Frontend использует текущие endpoint'ы проекта и предполагает, что backend запускается на порту `8080`. AI-итог требует настроенного `GEMINI_API_KEY` на стороне backend. Backend в этом архиве не изменён и не включён. Если каталог не загружается, сначала проверьте backend, подключение к базе и переменные окружения.
